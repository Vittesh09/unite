# Intro assets

- `milkyway.png` — equirectangular Milky Way dust map (RA × Dec), procedural CC0 bake used by Astro Walk. Replace with any CC0/self-owned equirect (≈1–3 MB) if you want a photographic band; set `milkywayUrl` in the SkyEngine opts.

Drop the Figma intro export here as:

- `intro.mp4` (preferred), or
- `intro.webm`

On cold start the splash plays this video when present. If the file is missing, Unite shows the infinity logo fallback for about 1.4 seconds.
